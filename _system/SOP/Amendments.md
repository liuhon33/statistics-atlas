# SOP amendments

Signed change history of the [[AGENTS|statistics vault SOP]]. The SOP holds the current rules only. This ledger records who changed them, when, where and why. Text not covered by a row is the original SOP that Codex finalized with the user on 2026-11-08. The pre-rebuild draft is kept in [[_system/SOP/history/SOP draft|SOP draft]] for historical reference only.

## Signing rule

Several agents edit the SOP (currently Codex and Claude). **Every agent that changes `AGENTS.md` signs the change here.**

1. Add a row to the table below with the next ID (A19, A20, …), the date (America/New_York), the agent, the SOP sections touched, what changed, and why or at whose request.
2. Edit the SOP text in place. Do not add inline signatures or markers to `AGENTS.md`; this row is the signature. Code comments and auxiliary records may cite the ID, e.g. `AGENTS A7`.
3. Never delete or rewrite another agent's row. If a change supersedes an amendment, say so in the new row.
4. Append a `schema` entry to `_system/Log.md` that names the amendment ID.
5. Keep the SOP to rules. Put procedures in the command skill (`.agents/skills/<name>/SKILL.md`), plugin and tool detail in [[_system/Map implementation]] or [[_system/Claude/Validator]], and history here.

Up to A17, each amended passage in `AGENTS.md` also carried an inline marker such as `*[Codex · A8]*`. A18 removed those markers, with the user's approval, and added the **Sections** column below so the same information stays recorded. Git history keeps the earlier text.
